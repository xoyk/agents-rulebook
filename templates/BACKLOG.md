# Backlog

Everything known to be worth doing, and nothing else. Read this before
proposing work. Add here rather than mentioning something once in a
conversation. Close an item by deleting it.

An item says what and why in one or two lines. If it needs a paragraph to
explain, it is not a backlog item yet; it is a question to ask.

## Where things go

**This file is an index. Items live in `backlog/`, one file per area.** Write
into the file for the area you are working in, at the end of its `## Bugs` or
`## Next` section.

| file | holds |
|---|---|
| [`backlog/other.md`](backlog/other.md) | anything with no area yet |

A new area gets a new file and a row here — a page, a flow, a subsystem: the
lines along which people actually split the work. Splitting one is cheaper than
letting it grow past the point where anybody reads it.

It is split so that two branches working on different areas never touch the
same file, which is the one kind of backlog conflict that appending cannot
prevent. The rule and its story are in `AGENTS.md`, under the backlog.
